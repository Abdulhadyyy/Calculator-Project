# Calculator Project

A simple beginner-level C++ calculator project for performing basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- User input
- Menu-driven operation selection

## Technologies Used

- C++

## Concepts Practiced

- Variables
- Data types
- User input and output
- Conditional statements
- Switch statements
- Basic arithmetic operations
- Functions

## Purpose

This project was created to practice basic C++ programming concepts and build a simple command-line calculator.
